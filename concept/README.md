# Life Ledger dark mode concept

Clickable design concept for Life Ledger: forest-green dark theme, pesos (₱).
Each screen is a standalone HTML page. Open `index.html` (the splash) and tap through.

Screens: splash, home, transactions, add transaction, budget, goals, bills, reports, calendar, settings.

This folder is a design reference only. It does not touch the app in `life-dashboard.html`.
