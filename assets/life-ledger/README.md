# Life Ledger Asset Library

Reusable assets for the Life Ledger dark-green personal finance PWA.

## Contents
- `branding/`: leaf symbol and wordmark SVGs.
- `illustrations/`: onboarding landscape and empty-state illustration.
- `icons/categories/`: category, income, and utility icons.
- `icons/bills/`: bill-specific icons.
- `icons/goals/`: savings-goal icons.
- `icons/navigation/`: navigation and action icons.
- `tokens/design-tokens.json`: shared colors, sizes, spacing, and radii.
- `ASSET_INVENTORY.md` / `.csv`: inventory and usage notes.
- `previews/`: asset contact sheet and visual previews.

## Usage
Use SVGs as external images in the PWA or inline them where CSS color inheritance is required. Keep charts, progress rings, buttons, and interactive controls as dynamic UI components. These are recreated assets based on the Life Ledger concept reference, not extracted original source artwork.

## Theme
Deep forest-green surfaces with mint-green primary actions, and orange, blue, purple, red, and teal category accents. Currency formatting should use Philippine pesos (₱).
